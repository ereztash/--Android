# M12 — production hardening

*"אל תעצור עד שהאפליקציה מוכנה לפרודקשן"* — don't stop until the app is production-ready.

M12 is not a feature milestone. It closes the gaps that only become visible once the features
exist, and states plainly what is still blocked and by whom.

## Two features that existed and did nothing

### The personal dictionary was never read

M6 built an encrypted store, a Keystore-backed key, an atomic write, a settings screen, and a
one-tap delete that destroys the key. Nothing read it. A user could add a word, watch the
keyboard go on calling it a misspelling, and reasonably conclude the setting was broken —
because it was.

Now `CorrectionEngine` takes the dictionary as a separate `WordSet`, so:

- an added word stops being an error, and prefix stripping applies to it too — `ולדני` is
  accepted once `דני` is;
- added words are offered as completions, **before** lexicon words.

Kept as a separate set rather than merged into the lexicon on purpose: the lexicon is a fixed,
hash-locked artifact that every measured number was taken against, and the personal dictionary
is small, mutable and per-user. Merging them would make every accuracy figure in this
repository a claim about a set that varies per device. A test asserts an empty dictionary
changes nothing, which is what keeps the M5 and M10 numbers meaning what they say.

**Ranking personal words first is a design decision with no measurement behind it** — there is
no corpus of personal dictionaries — and is recorded as such rather than dressed up in a
weight that would look derived.

### The undo path for automatic replacement was unreachable

`HebrewImeService` carried a `lastReplacement` field and a backspace branch to reverse an
automatic correction with one keystroke. Nothing ever set the field: `shouldAutoReplace` is
implemented and measured but never called. The branch could not execute.

Dead code that describes a feature the app does not have is worse than no code, because it
reads like evidence the feature was considered and handled. Removed, and the decision recorded
where the behaviour is:

> On the unbiased golden corpus the shipped configuration would auto-replace 24.25% of
> misspellings, of which **1.90% are wrong** — text the user meant, silently replaced with text
> they did not write, possibly noticed only much later. The alternative costs one tap.

The operator asked for a keyboard that *offers* corrections. This one only offers.

## Re-verified, not assumed

| | |
|---|---|
| Gates | **16**, every control demonstrated red in the same run |
| Tests | **179**, 0 failures, 0 skipped |
| Lint | 0 issues |
| Release APK | 5,161,766 bytes — inside a budget written down after measuring it |
| Release AAB | 5,940,182 bytes |
| DEX after R8 | 1,922,156 bytes, from 28,527,620 |
| Real-word check cost | 3.7 µs/call — *JVM on the build host, NOT a device* |

The 3.7 µs answers a question M11 left open: the detector re-examines the same word on every
keystroke while the user types the one after it, and whether that waste was worth caching away
was not obvious. Measured against the ~239 µs the rest of prediction costs, it is not. Now it
is a measurement rather than an assumption.

## Still blocked, and by whom

Nothing below is something more work here can resolve.

| What | Blocked on |
|---|---|
| Every device-dependent row in the QA matrix — 15 of them | **A physical Android device.** Nothing in this repository has ever run on one. |
| p95 keystroke latency | A device, *and* the keyboard enabled as the active IME — a benchmark cannot arrange that itself without `WRITE_SECURE_SETTINGS`. |
| Signed release AAB | **Signing secrets.** The pipeline reads an untracked `keystore.properties` and falls back to unsigned; it needs the key. |
| Store listing, Data Safety submission, internal testing track | A Play Console account, and NOTICE 1's targetSdk deadline. |

The verdict in [`RELEASE_READINESS.md`](../RELEASE_READINESS.md) is unchanged and is not
softened: **NOT READY**. There is no "ready except for". The code is complete and measured; the
app has never been used.
